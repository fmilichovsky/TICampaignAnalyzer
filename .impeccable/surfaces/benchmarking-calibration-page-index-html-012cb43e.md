# Stake calibration page

Scope: the maintainer's stake calibration page (`benchmark calibrate open`), opened from file:// on a desktop beside an editor. Mode: Operate. Source of decisions: issue #464 and its design brief comment ("Tide Table"), pinned whole.

Audience and job: the maintainer (and, through the copied hash, an agent) drags one measure's reference and must see, without the page moving, what changes level, whose members change, and the real events on each side of each cut-off; then copies a snippet.

## Direction contract

seed: none (pinned)

THESIS: Every number has a fixed column; only the figures change. Refuses the KPI-card dashboard and any layout that reflows while the slider moves.

OWN-WORLD: Cool chart-white ground #F6F7F4, navy-black ink #16202C, navy header bar. Depth tints for levels (#D5DCD6, #A9CFE3, #4F8DB8, #1C3F66; the two deep ones textured). Chart magenta #B0177E for rises and cut-off lines, buff #C9A24A for drops, pale blue-grey for keeps. Night-chart dark theme with the same roles. One system sans, tabular figures, 1-device-pixel rules, small radii.

STORY: Pick a measure, slide its reference, read the three totals and What moves, check members, and judge the cut-offs by the real events that sit on each side.

FIRST VIEWPORT: Header with campaigns, clamp, reset, copy; left column of measure chips, slider, the 270 px window chart and the two tide-table cut-off lists; right column of totals, member verdict strip and What moves.

SIGNATURE: Each cut-off set like a tide-table entry: bold magenta cut-off figure, five single-line events above and below with the share column first, a magenta rule at the cut.

REFUSE: KPI cards, nautical decoration, chart-paper texture, anything in the left column that grows while sliding.
